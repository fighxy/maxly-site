# План сайта Maxly

ТЗ для агента, который будет собирать сайт. Всё в `[КВАДРАТНЫХ СКОБКАХ]` — плейсхолдеры, их не заполнять самому.

## Архитектура
- Статический сайт: чистые HTML и CSS, без фреймворка и сборщика. JS только для определения ОС и вкладок.
- Публикация: GitHub Pages из `main` (корень репозитория), свой домен потом через `CNAME` [ДОМЕН].
- Ссылки на загрузку ведут только на постоянные релизы `fighxy/Maxly` (`ios-latest`, `android-latest`, `desktop-latest`).
- Без внешних ресурсов: никаких CDN, шрифтов, счётчиков и cookie.
- Структура:
```
index.html
download/index.html
download/ios/index.html
download/android/index.html
download/desktop/index.html
faq/index.html
privacy/index.html
disclaimer/index.html
terms/index.html
contacts/index.html
404.html
assets/css/site.css
assets/js/os.js
assets/img/ (лого, скриншоты WebP)
og.png
robots.txt
sitemap.xml
```
- У каждой страницы свои title, description, canonical и Open Graph (`/og.png`, 1280×640).
- Общие шапка (лого, «Скачать», FAQ, GitHub) и подвал (документы, контакты, «Неофициальный клиент, не связан с MAX»).

## Дизайн
- Тема тёмная по умолчанию: фон `#000`, поверхности `#0E0E10` и `#17171A`, текст `#F5F5F7`, вторичный `#A1A1A6`. Светлая тема через `prefers-color-scheme`.
- Акцент — градиент из лого (синий, голубой, фиолетовый), цвета взять пипеткой и записать в `--accent-1..3`. Только на основной кнопке, в hero и иконках фич.
- Шрифт: `-apple-system, "SF Pro Text", "Segoe UI", Roboto, sans-serif`. H1 56/64 на десктопе и 40/48 на телефоне, H2 32, текст 17, вторичный 15. Без курсива, `letter-spacing` не больше 0.
- Контейнер до 1120 px, отступы секций 96 px (64 на телефоне). Карточки фич: 3, 2 и 1 колонка.
- Кнопки от 44 px высотой, скругление 14 px. Карточки со скруглением 20 px и рамкой `rgba(255,255,255,.08)`. FAQ на `<details>`.
- Скриншоты в рамках устройства, WebP, `loading="lazy"`, с `alt`.
- Анимации только лёгкое появление, с учётом `prefers-reduced-motion`.
- Контраст AA, видимый фокус, клавиатура, `lang="ru"`. Страница с CSS до 100 КБ без скриншотов.
- Русская типографика: «ёлочки», тире —, многоточие ….

  - **Мини-приложения и боты.** Работают так же, как в официальном клиенте.

### `/download/ios` — «Maxly для iPhone»
- Ссылка: [Maxly.ipa](https://github.com/fighxy/Maxly/releases/download/ios-latest/Maxly.ipa), сразу файл, без ZIP.
- iOS 17 или новее, установка через sideload-приложение (например, eSign). Прямо написать: в App Store нет.
- Шаги со скриншотами (снимает Swift Guy): скачать, открыть в eSign, установить и доверить профилю.

### `/download/android` — «Maxly для Android»
- Ссылка: [Maxly.apk](https://github.com/fighxy/Maxly/releases/download/android-latest/Maxly.apk).
- Android 8.0 или новее. Прямо написать: в Google Play нет.
- Шаги со скриншотами: скачать в браузере, открыть и разрешить установку из браузера, установить и войти по номеру.

### `/download/desktop` — «Maxly для компьютера»
Три вкладки, ОС выбирается автоматически.
- Windows: [Maxly.msi](https://github.com/fighxy/Maxly/releases/download/desktop-latest/Maxly.msi), пройти установщик. [ЗАМЕНЯЕТ ORBITLE / СТАВИТСЯ РЯДОМ].
- macOS: [Maxly.dmg](https://github.com/fighxy/Maxly/releases/download/desktop-latest/Maxly.dmg), перетащить в «Программы». Не подписано: первый запуск через правый клик и «Открыть».
- Linux: [Maxly.deb](https://github.com/fighxy/Maxly/releases/download/desktop-latest/Maxly.deb), `sudo apt install ./Maxly.deb`.
- Для голосовых, кружков и видео нужен `ffmpeg` в PATH, короткая инструкция для каждой ОС.
- Версии ОС и архитектуры: [ПРОВЕРИТЬ].

## `/faq` — «Частые вопросы»
- title: «Вопросы о Maxly». description: «Официальное ли это приложение, безопасно ли им пользоваться и почему его нет в App Store и Google Play.»
- **Это официальное приложение?** Нет. Maxly — независимый клиент с открытым кодом, MAX с ним не связан.
- **Безопасно ли?** Приложение не собирает аналитику, а сессия хранится только на устройстве. Сообщения при этом идут через серверы MAX, как и в официальном приложении. Код открыт, его можно проверить.
- **Могут ли заблокировать аккаунт?** Гарантировать, что нет, мы не можем: сторонние клиенты могут противоречить правилам MAX. Решение пользоваться им за вами.
- **Почему нет в App Store и Google Play?** Это неофициальный клиент, поэтому распространяется он только через релизы на GitHub.
