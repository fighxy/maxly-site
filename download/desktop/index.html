Maxly для компьютера

Windows, macOS и Linux. Минимальные версии систем ещё сверяются — берите сборку своей ОС из постоянного релиза.

Windows

Пройдите установщик Maxly.msi.

Скачать Maxly.msi

Заменяет ли установщик Orbitle или ставится рядом, ещё не решено. Пока считайте, что Maxly ставится отдельно и войти нужно заново.

ffmpeg. Для голосовых, кружков и видео нужен ffmpeg в PATH. В терминале: winget install Gyan.FFmpeg. Откройте новое окно и проверьте ffmpeg -version.

macOS

Откройте Maxly.dmg и перетащите приложение в «Программы».

Скачать Maxly.dmg

Сборка не подписана. Первый запуск: правый клик по приложению и «Открыть».

ffmpeg. Для голосовых, кружков и видео нужен ffmpeg в PATH. Если стоит Homebrew: brew install ffmpeg. Проверка: ffmpeg -version.

Linux

Скачайте пакет и установите его из текущей папки.

Скачать Maxly.deb
sudo apt install ./Maxly.deb

ffmpeg. Для голосовых, кружков и видео нужен ffmpeg в PATH: sudo apt install ffmpeg. Проверка: ffmpeg -version.
